# Checklist Akhir Responsi Flutter

## Kode dan aplikasi
- [ ] Project dibuat dari `flutter create`.
- [ ] `flutter pub get` berhasil.
- [ ] `flutter analyze` sudah diperiksa dan tidak ada error yang belum ditangani.
- [ ] `flutter test` berhasil.
- [ ] Aplikasi dapat dijalankan pada emulator/perangkat.
- [ ] Home menampilkan data cuaca yang berasal dari Open-Meteo.
- [ ] Pencarian kota melakukan request Geocoding API.
- [ ] Pemilihan kota memicu request Weather Forecast API dengan koordinat lokasi.
- [ ] Loading, hasil kosong, dan error ditangani.
- [ ] Lokasi favorit tersimpan dan dapat dibaca kembali setelah aplikasi dimulai ulang.

## README dan GitHub
- [ ] Identitas pengembang telah diisi.
- [ ] URL repository telah benar.
- [ ] Screenshot Home Screen asli telah ditambahkan.
- [ ] Screenshot Search Screen asli telah ditambahkan.
- [ ] Struktur proyek, API, MVVM, dan Local Storage dijelaskan.
- [ ] `pubspec.lock` ikut dikirim.
- [ ] Perubahan terakhir sudah di-commit dan di-push.
- [ ] Akses repository sesuai instruksi dosen.

## Video dan pengumpulan
- [ ] Video memperlihatkan demo aplikasi.
- [ ] Video menjelaskan file Model, View, ViewModel, dan Service.
- [ ] Video menjelaskan request GET, parsing JSON, state, dan Local Storage.
- [ ] Tautan video dapat diakses.
- [ ] Formulir pengumpulan telah diisi dan diperiksa kembali.
